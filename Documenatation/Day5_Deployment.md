# Day 5 – Backend Deployment

## Objective
Deploy the backend service to a free cloud hosting platform (Render).

## Backend Information
- Runtime: Node.js
- Framework: Express.js
- Database: PostgreSQL
- Branch: devops-integration

## Deployment Platform
Render (Free Tier)

## Steps Followed
1. Created Render account.
2. Connected GitHub account.
3. Requested access to the project repository.
4. Prepared backend for deployment.
5. Verified backend runs successfully locally.

## Environment Variables
PORT=5001
DATABASE_URL=<Cloud Database URL>
JWT_SECRET=<Secret Key>

## Deployment Status
Pending organization permission to access the repository.

## Expected Result
- Backend accessible using a public Render URL.
- API endpoints available online.
